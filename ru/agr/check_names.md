# Проверка наименований

### Структура имени файла .ifc

```
НН_К01_С01_АР_АГР_R01.ifc
│  │   │   │  │   │
│  │   │   │  │   └─ R01: Версия/Ревизия документа
│  │   │   │  └──── АГР: код организации/типа документа
│  │   │   └──── АР: код раздела проектной документации
│  │   └──────── С01: Секция 01
│  └──────────── К01: Корпус 01
└─────────────── НН: код города/объекта (Нижний Новгород)
```

Программа разбивает имя по `_`, распознаёт коды и формирует человекочитаемое описание:
```
К01 → "Корпус 1"
С01 → "Секция 1"  
АР  → "Раздел АР"
→ Итог: "Корпус 1, Секция 1, Раздел АР"
```

### Состав разделов проектной документации

Постановление Правительства №87 от 16.02.2008 утверждает **состав разделов проектной документации**. Ключевые соответствия:

|Код|Название раздела|№ раздела (по ПП №87)|Краткое назначение|
|---|---|---|---|
|**ПЗ**|Пояснительная записка|1|Общие данные, технико-экономические показатели, основания для проектирования|
|**СХП**|Схема планировочной организации земельного участка|2|Генплан, благоустройство, транспорт, вертикальная планировка|
|**АР**|Архитектурные решения|3|Планы, фасады, разрезы, спецификации, ведомость отделки|
|**КР**|Конструктивные решения|4|Фундаменты, каркас, перекрытия, узлы, спецификации материалов|
|**ИОС.1 – ИОС.10**|Инженерные системы|5–13*|ОВ, ВК, ЭОМ, СС, ГС, АОВ, АПС, АУПТ, УМ, ЭОМ и др.|
|**ПОС**|Проект организации строительства|14|Календарные графики, стройгенплан, логистика, безопасность|
|**ПОМ**|Проект организации ремонта (или демонтажа)|15|Мероприятия при реконструкции/капитальном ремонте|
|**ОДИ**|Обеспечение доступа инвалидов|16|МГН, пути движения, санузлы, signage|
|**ТИ**|Тепловая изоляция|17|Расчёты, узлы, спецификации изоляционных материалов|
|**ООС**|Охрана окружающей среды|18|Воздействие на экологию, природоохранные мероприятия|
|**ПБ**|Пожарная безопасность|19|Противопожарные требования, эвакуация, системы защиты|
|**СМ**|Сметная документация|20|Локальные, объектные сметы, сводный сметный расчёт|
|**ЭП**|Экспертный раздел|21|Сводная информация для государственной экспертизы|



### Примеры
Ввод:
1. НН_К00_С00_БиО_АГР_3.ifc
2. НН_К01_С01_АР_АГР.ifc
3. НН_К14_С01-С03_АР1_АГР.ifc

Вывод:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<FileList>
	<File>
		<Number>1</Number>
		<n>НН_К00_С00_БиО_АГР_3</n>
		<Description>Раздел БиО, версия 3</Description>
		<Section>Раздел 5 «Сведения об инженерном оборудовании» (подраздел БиО)</Section>
	</File>
	<File>
		<Number>2</Number>
		<n>НН_К01_С01_АР_АГР</n>
		<Description>Корпус 1, Секция 1, Раздел АР</Description>
		<Section>Раздел 3 «Архитектурные решения»</Section>
	</File>
	<File>
		<Number>3</Number>
		<n>НН_К14_С01-С03_АР1_АГР</n>
		<Description>Корпус 14, Секции 1–3, АР часть 1</Description>
		<Section>Раздел 3 «Архитектурные решения» (часть 1)</Section>
	</File>
</FileList>
```
